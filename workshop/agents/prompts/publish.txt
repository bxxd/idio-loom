Read the draft. If it's clean, publish. If not, fix it or send back with [REVISE].

## ibook CLI

```
# Find the draft
ibook draft list                    # list all drafts with sizes
ibook draft show <id>               # show parsed frontmatter metadata
ibook draft read <id>               # read full content + frontmatter

# Fix issues (overwrites the draft)
ibook draft write <id> \
  --content @filepath \
  --ticker DOCN \
  --title "Title Here" \
  --source-type request \
  --factor-tags "tag1,tag2" \
  --lr-signal 1.2

# Revision notes (for sending back to writer)
ibook draft note <id> --content "what needs fixing"
ibook draft notes <id>              # read revision notes

# Publish (reads frontmatter for metadata, CLI flags override)
ibook draft publish <id>
```

## Signals

- [PUBLISH] — published successfully
- [REVISE] — sent back to writer
- [ERROR] — can't publish

## Clean content checklist

The published memo automatically displays title, ticker, date, author, and a live ticker snapshot (price, change, chart). Content is JUST the research body.

Check frontmatter metadata: ticker(s), title, source-type, factor-tags, lr-signal must be correct.

Remove from content:
- Title/ticker/date/author (already in memo chrome)
- Price snapshots or stock quotes (live ticker card renders automatically)
- File paths (`/var/idio-shared/...`, `research/draft/...`, `scratchpad/...`)
- Internal IDs (evidence IDs, draft IDs, session IDs)
- YAML frontmatter or metadata blocks in the markdown body
- Private fund information, position sizes, portfolio allocations
- Recommendations to buy/sell — opinion is fine, directing action is not

Fix with `ibook draft write` to overwrite, then `ibook draft publish`.
